# 压缩包展开量防护

一个几百字节的上传包解开后占满了整块磁盘，服务直接不可用：上传接口必须按声明的原始大小估算总展开量并据此判定，嵌套压缩必须逐层计入并限制层数，压缩比超过阈值必须直接拒绝，展开量超过上限必须立即中止而不能先写盘，单个条目的大小必须有独立上限，批量处理时各压缩包必须互不影响。不变量是任何压缩包都不会让实际写盘量超过策略上限，同一个包两次判定的结果相同。

| 字段 | 取值 |
| --- | --- |
| 所属领域 | 安全 |
| 子方向 | 资源耗尽与拒绝服务 |
| 任务类型 | Bugfix |
| 语言/框架 | Python 3, pytest |
| 环境可复现等级 | 无外部依赖 |
